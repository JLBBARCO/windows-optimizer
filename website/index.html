Otimizador de Windows

Programa desenvolvido em Python feito para executar comandos para limpar arquivos temporários, atualizar todos os programas, fazer download de uma nova imagem do sistema operacional, corrigir erros de ícones, entre outros problemas que possam acontecer.

Comandos

Para executar o otimizador, copie e cole um dos comandos abaixo no PowerShell:

Última versão estável

irm https://raw.githubusercontent.com/JLBBARCO/windows-optimizer/main/core-app/run.ps1 | iex

Versão beta

irm https://raw.githubusercontent.com/JLBBARCO/windows-optimizer/beta/core-app/run.ps1 | iex

Funcionalidades

  • Limpeza de arquivos temporários
  • Atualização de programas
  • Download de nova imagem do sistema operacional
  • Correção de erros de ícones
  • Entre outros problemas que possam acontecer
